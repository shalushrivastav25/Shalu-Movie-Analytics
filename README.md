# Movie & TV Content Analytics Dashboard
Prepared for Shalu — Big Data Mini Project.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`

## Deploy on Streamlit Community Cloud
Upload `app.py`, `requirements.txt`, and `movie_dataset.csv` to a GitHub repository. On Streamlit Community Cloud, create an app from that repository and set the main file path to `app.py`.

The bundled dataset is generated sample data for demonstration, not real streaming-platform data.
